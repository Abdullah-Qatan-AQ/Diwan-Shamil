# المعجم المحلي متعدد المصادر

يستخدم التطبيق فهارس JSON محلية لشرح الكلمات دون طلبات خارجية. يحتفظ `lexicon.json` بالمصادر المفتوحة المضمّنة، ويضم `lexicon-core.json` حاليًا **35,602 مدخل عربي** للعمل السريع دون اتصال، بينما يوفّر `poetry-coverage.json` قائمة بكل الكلمات المستخرجة من نصوص القرآن والحديث والشعر المحلي؛ ويبلغ عدد كلمات التغطية **322,579 كلمة**. وتُوزَّع قائمة التغطية نفسها على ثمانية ملفات داخل `coverage/` مع فهرس `coverage/index.json`.

| المصدر | المحتوى | الرخصة |
|---|---|---|
| [Arabic WordNet 4.1](https://github.com/Salah-Sal/arabic-wordnet-v4) | مجموعات دلالية وتعريفات عربية | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| [Kaikki / Wiktionary العربية](https://kaikki.org/dictionary/Arabic/index.html) | مداخل Wiktionary العربية والصيغ المصرفة | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| `original-glosses.json` | 318 معنى عربيًا أصليًا صيغ خصيصًا لهذا المشروع | MIT باسم عبدالله قطان |

لا تُضاف أي تعريفات من مواقع تجارية أو مصادر لا تسمح بإعادة التوزيع. وقبل إدخال أي تعريف يمرّ عبر بوابة جودة تستبعد النص الإنجليزي، والنقل الصوتي اللاتيني، والروابط، ووسوم القوالب. لذلك قد تظهر لبعض الكلمات رسالة «لا يوجد تعريف عربي موثّق» بدل اختراع معنى غير صحيح؛ وهذا مقصود للحفاظ على الدقة.

كود المشروع والسكربتات الجديدة التي كُتبت للمشروع، وكذلك `original-glosses.json`، مرخّصة بموجب MIT باسم عبدالله قطان. أما ملفات القرآن والحديث والشعر، وملفات المعجم المستوردة أو المشتقة منها، فتظل خاضعة لتراخيصها وملاحظات المصدر المبينة أدناه، ولا يمكن إعادة ترخيصها إلى MIT من طرف واحد.

تمت مراجعة **Qabas** كمصدر صرفي عربي مفتوح، لكن الموقع يوضح أنه لا يوزّع نصوص التعريفات المعجمية نفسها، ولذلك لم تُنسخ منه تعريفات إلى التطبيق. كما أن استخدام بياناته يقتصر هنا على التحقق النظري من الصيغ، لا على نسخ محتوى محمي.

تقوم الواجهة بتصفية أي تعريف يحتوي حروفًا لاتينية، فلا تعرض الشروحات الإنجليزية. تُعرض المعاني الأصلية من `original-glosses.json` أولًا، مع إظهار مصدرها وترخيصها. أما الكلمات التي لا تملك تعريفًا عربيًا موثّقًا فلا يُخترع لها معنى ولا تُنسب إلى مصدر؛ تظهر بدلًا من ذلك رسالة عربية تفيد بأنها مغطاة سياقيًا في نص الديوان.

تُطبّع المفاتيح بإزالة التشكيل وتوحيد الهمزات، ويستخدم التطبيق بحثًا صرفيًا محافظًا عند النقر على كلمة ملحقة في البيت الشعري. البيانات الخارجية تبقى خاضعة لشروط تراخيصها، وهذه الملاحظات مصدرية وليست استشارة قانونية.

لإعادة إنشاء ملف التغطية الخفيف بعد تغيير نصوص الشعر:

```bash
node scripts/build-poetry-coverage.mjs
node scripts/build-poetry-coverage-shards.mjs
npm run build:original-glosses
npm run verify:lexicon
```

ولإعادة بناء المعجم مع تطبيق بوابة الجودة:

```bash
npm run quality:lexicon
```

ملف المعاني الأصلية موثق تفصيلًا في `ORIGINAL-GLOSSES-LICENSE.md`. ترخيص MIT لا يغيّر شروط مصادر البيانات الخارجية.
