# الديوان الشامل

واجهة عربية RTL للقراءة والبحث في القرآن والحديث والسيرة وقصص الأنبياء والشعر والأدب والمخطوطات. لا تُخزّن هذه النسخة كتباً كاملة داخل المستودع؛ بل تهيّئ تجربة عرض المحتوى داخل الواجهة مع فهرس 200 مصدر، وتدعم تنزيل النص المقروء والتخزين المؤقت للعمل دون اتصال.

## التشغيل

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## ملاحظات المصادر

يجب ربط كل باب في بيئة الإنتاج بمصادر رقمية مرخّصة أو واجهات API عامة، مع احترام شروط الاستخدام وحقوق النشر، وعرض المحتوى داخل القارئ بدلاً من إغراق المستخدم بعناوين الواجهات التقنية. يتضمن التطبيق حالياً محتوى تجريبياً محلياً كي يعمل دون اتصال، وفهرساً قابلاً للتوسعة لمئتي مصدر.
