# Crypto Hub — Earn · Wallet · Swap

مشروع ثابت لمجلد إحالات ومحفظة غير حاضنة وواجهة تداول تجريبية. النسخة الحالية تبدأ افتراضياً على **Testnet**. يوجد وضع Mainnet اختياري يُفعّل يدوياً بكتابة `MAINNET` من داخل الواجهة، ولا يتم إرسال أي معاملة تلقائياً.

## الشبكات والوظائف

- **EVM Testnets:** Ethereum Sepolia (`11155111`)، BNB Chain Testnet (`97`)، Polygon Amoy (`80002`)، Arbitrum Sepolia (`421614`)، وAvalanche Fuji (`43113`). يتم جلب `chainId` والأرصدة عبر JSON-RPC عام مع مهلة زمنية.
- **TRON Shasta:** اشتقاق عنوان TRON من المفتاح المحلي وقراءة رصيد tTRX عبر TronGrid Shasta. لم يتم تفعيل بث تحويل تلقائي.
- **Bitcoin Testnet:** اشتقاق عنوان Native SegWit testnet وفق BIP84 للمسار `m/84'/1'/0'/0/0`، باستخدام HASH160 الصحيح ومقدمة `tb1`، وقراءة الرصيد من Mempool Testnet API.
- **Solana Devnet:** اشتقاق عنوان SLIP-0010/Ed25519 للمسار `m/44'/501'/0'/0'` وقراءة الرصيد من Solana Devnet JSON-RPC.
- **DEX Swap:** واجهة آمنة تجريبية فقط. لا توجد معاملة أو allowance أو توقيع أو بث حتى تتم إضافة تكامل عقود موثقة ومحاكاة ومراجعة مستقلة.

## الحماية المحلية

تُولد عبارة BIP39 محلياً عبر `ethers.js`، ثم تُشفّر في المتصفح باستخدام PBKDF2-HMAC-SHA256 مع 250,000 دورة وAES-256-GCM. لا تُرسل العبارة أو المفاتيح الخاصة إلى RPC أو APIs. توجد سياسة CSP مقيّدة، ومهلات للشبكات العامة، وحارس وضع يمنع التبديل إلى Mainnet إلا بتأكيد يدوي صريح، مع بقاء Testnet هو الوضع الافتراضي.

المفتاح الخاص يبقى في الذاكرة فقط بعد فتح المحفظة ويُمسح عند القفل. لا تُدخل عبارة الاسترداد في أي موقع أو widget خارجي.

## اختبار وتشغيل

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`. يجب أن يظهر تحذير Testnet في قسم المحفظة. للتحقق من صحة JavaScript:

```bash
node --check app.js
node --check config.js
```

تم التحقق من استجابة `eth_chainId` للشبكات الخمس، وظهرت القيم المطابقة للإعدادات. لا يمكن لأي فحص محلي أن يضمن انعدام الثغرات؛ قبل أي استخدام مالي يجب إجراء تدقيق مستقل ومراجعة الاعتماديات وواجهات RPC وعقود DEX.

## Android

غلاف Android موجود في `android_app/` ويستخدم WebView:

```bash
cd android_app
flutter pub get
flutter build apk --release --dart-define=EARNLY_URL=https://YOUR_DEPLOYED_DOMAIN
```

لا تنشر التطبيق على Mainnet قبل إضافة طبقة مراجعة معاملات واضحة، والتحقق من `chainId` والعناوين والرسوم، واختبارات توقيع مستقلة لكل شبكة.


## واجهة الهاتف والإحالات

تمت إضافة تخطيط متجاوب للهواتف مع قائمة جانبية قابلة للفتح، وتحويل أزرار الإحالات إلى روابط HTML مباشرة تفتح الرابط الصحيح في تبويب جديد.


## طبقات المعاملات المستقلة

يحتوي `chain-layers.js` على بناة معاملات منفصلة لـ ERC-20 وTRC-20 وSPL وBitcoin PSBT، بالإضافة إلى قراءة `allowance` وموافقة محددة المبلغ ومحاكاة EVM. لا توجد عناوين عقود توكن أو Router مفترضة داخل المشروع؛ يجب إدخال عناوين موثقة لكل شبكة، والتحقق من `chainId` والكود قبل التوقيع. لا تبث هذه الطبقات تلقائيًا.

- **ERC-20:** `balanceOf` و`decimals` و`allowance` و`transfer` و`approve` محدد المبلغ.
- **TRC-20:** قراءة بيانات العقد وبناء `transfer`.
- **Solana/SPL:** بناء تحويل SOL وتعليمات SPL.
- **Bitcoin:** بناء PSBT من UTXO والتحقق من الرصيد والمخرجات.
- **Swap:** إعدادات Router وslippage موجودة، لكن لا تُستخدم حتى تُدخل عناوين موثقة؛ الموافقات غير المحدودة ممنوعة.

التوقيع والبث يتطلبان دمج واجهة مراجعة لكل طبقة، ويجب أن يحدثا محليًا بعد مراجعة المستخدم.
