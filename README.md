# الديوان الشامل

تطبيق عربي للقراءة دون اتصال. هذه النسخة تضمّن البيانات داخل المستودع بدل الاعتماد على API أثناء الاستخدام:

- `data/quran.json`: القرآن الكريم من `risan/quran-json`.
- `data/ara-bukhari.json`: صحيح البخاري من `fawazahmed0/hadith-api`، الفرع `1`.
- `data/ara-muslim.json`: صحيح مسلم.
- `data/ara-tirmidhi.json`: جامع الترمذي.
- `data/ara-abudawud.json`: سنن أبي داود.
- `data/ara-nasai.json`: سنن النسائي.
- `data/ara-ibnmajah.json`: سنن ابن ماجه.
- `data/ara-malik.json`: موطأ مالك.
- `data/poetry/`: مجموعة شعر عربية محولة من ملف Kaggle إلى 76 ملف JSON، بإجمالي 75,022 قصيدة.

## المصادر والتحقق

تم التحقق من وجود الملفات عبر GitHub والروابط الخام قبل تضمينها. مستودع القرآن يرفق مراجعة ترخيص للمصادر، ومستودع الأحاديث يرفق ملف `LICENSE`. لا تُفهم عبارة «مفتوح» على أنها ملكية عامة تلقائيًا؛ يجب احترام شروط كل مستودع ونسبة المصدر عند إعادة التوزيع.

المستودعان `mhamdaqa/arabic-poetry-dataset` و`ahmed-badawy/islamic-data` بالمسارات المذكورة في الطلب أعادا 404 وقت التحقق، لذلك لم تُنسخ بيانات غير موجودة أو منسوبة خطأً.

مجموعة الشعر المضمنة من `mdanok/arabic-poetry-dataset` مرخصة كقاعدة بيانات تحت ODbL 1.0، ومصدرها المعلن هو `aldiwan.net`. لا نعرضها على أنها CC0 أو ملكية عامة؛ راجع `data/POETRY-LICENSE`. أما ويكي مصدر فليس كله ملكية عامة؛ بعض النصوص CC BY-SA وبعضها Public Domain بحسب وسم كل صفحة، لذلك لا يجوز نسخ التفريغ كله إلى التطبيق دون حفظ الإسناد والترخيص لكل نص.

## التشغيل

```bash
python3 -m http.server 4173
```

بعد تنزيل ملفات التطبيق، يعمل قارئ القرآن وكتب الحديث من ملفات `data/` المحلية ولا يحتاج اتصالاً أثناء القراءة.
