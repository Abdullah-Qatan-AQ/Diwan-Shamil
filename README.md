# الديوان الشامل

**مكتبة عربية شخصية للقراءة والبحث دون اتصال.** يجمع الديوان الشامل القرآن الكريم، وكتب الحديث، وموسوعة الشعر العربي في تجربة عربية هادئة وسريعة، مع حفظ المفضلة ومواضع القراءة داخل جهاز المستخدم.

> مشروع مفتوح المصدر من **Abdullah Qatan**، مبني كتطبيق ويب تقدمي (PWA) يعمل من المتصفح ويمكن تثبيته على الهاتف أو الحاسوب.

## لماذا الديوان الشامل؟

- قراءة القرآن الكريم مع فهرس السور والبحث داخل السورة وتغيير حجم الخط.
- البحث في ثمانية كتب حديث مع فلترة حسب القسم والموضوع والطول والدرجة.
- استكشاف أكثر من 75 ألف قصيدة عربية بتحميل تدريجي يحافظ على سلاسة التطبيق.
- **مفضلة شخصية** لحفظ السور والأحاديث والقصائد والعودة إليها لاحقًا.
- **مواضع قراءة مستقلة**؛ لكل آية وحديث وقصيدة زر موضع خاص لاستئناف القراءة من المكان الذي توقفت عنده.
- ثيمات رملي، ليلي، أخضر، وورقي، مع تذكر آخر سورة وحجم الخط.
- بحث عربي مرن يتعامل مع التشكيل وبعض اختلافات الهمزات والياء والتاء المربوطة.
- نسخة احتياطية قابلة للتصدير والاستيراد بصيغة JSON.
- تنزيل المكتبة الأساسية والعمل دون اتصال عبر Service Worker وCache API.
- زر لإعادة تعيين بيانات التطبيق المحلية عند الحاجة، مع تأكيد واضح قبل المسح.

## التشغيل محليًا

لا يحتاج المشروع إلى خطوة بناء أو مدير حزم. شغّل خادم ملفات ثابتًا من جذر المستودع:

```bash
python3 -m http.server 4173
```

ثم افتح [http://localhost:4173](http://localhost:4173). لا يعمل التطبيق بشكل صحيح عند فتح `index.html` مباشرة عبر `file://` لأن المتصفح يمنع بعض طلبات الملفات المحلية.

## النشر

المشروع جاهز للنشر على GitHub Pages أو أي استضافة ملفات ثابتة. يحتوي المستودع على Workflow اختياري في `.github/workflows/pages.yml` ينشر محتوى الفرع `main` تلقائيًا عند تفعيله من إعدادات GitHub Pages باستخدام GitHub Actions.

## البيانات والمصادر

البيانات مضمّنة داخل المستودع حتى يعمل القارئ أثناء انقطاع الاتصال:

- `data/quran.json`: القرآن الكريم من `risan/quran-json`.
- `data/ara-bukhari.json`: صحيح البخاري من `fawazahmed0/hadith-api`، الفرع `1`.
- `data/ara-muslim.json`: صحيح مسلم.
- `data/ara-tirmidhi.json`: جامع الترمذي.
- `data/ara-abudawud.json`: سنن أبي داود.
- `data/ara-nasai.json`: سنن النسائي.
- `data/ara-ibnmajah.json`: سنن ابن ماجه.
- `data/ara-malik.json`: موطأ مالك.
- `data/poetry/`: مجموعة شعر عربية محولة من ملف Kaggle إلى 76 ملف JSON، بإجمالي 75,022 قصيدة.

راجع `data/HADITH-SOURCES.md` و`data/POETRY-LICENSE` لتفاصيل المصدر والترخيص. وجود البيانات في مستودع مفتوح لا يعني أنها ملكية عامة؛ يجب احترام شروط كل مصدر ونسبته عند إعادة الاستخدام.

## الخصوصية

لا يحتاج التطبيق إلى حساب أو خادم خلفي. المفضلة، مواضع القراءة، الإعدادات، والنسخ الاحتياطية تبقى في تخزين المتصفح المحلي على جهاز المستخدم. يمكن حذفها من الإعدادات عبر **إعادة تعيين كل التطبيق**.

## التقنية

HTML وCSS وJavaScript حديثة بدون إطار عمل، مع دعم RTL، وService Worker للتخزين المؤقت، وواجهة PWA قابلة للتثبيت. رخصة المشروع البرمجية هي [MIT](LICENSE)، مع بقاء تراخيص مجموعات البيانات الخارجية كما هي موضحة في ملفات المصادر.

## المساهمة

الاقتراحات والإبلاغ عن الأخطاء مرحب بهما عبر Issues. عند إضافة مصدر بيانات جديد، يرجى توثيق مصدره وترخيصه بوضوح وعدم تضمين بيانات لا يسمح ترخيصها بإعادة التوزيع.
